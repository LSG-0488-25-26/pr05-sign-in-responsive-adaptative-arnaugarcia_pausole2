# GYM BROS
- Gym bros es una app d'android que simula un registre i login amb pantalles adaptative + responsive i navegació

# LOGIN
- Permet iniciar sessió amb les dades que t'has registrat en el "registre"
- Valida que les dades existeixin
- Es responsive
- Es adaptative en funció de l'altura màxima del dispositiu, mostrant / ocultant el banner

# REGISTRE
- Permet registrar un sol usuari i guardar les dades (les dades no son persistents)
- Validació de camps del registre
- Es responsive
- Es adaptative en funció de l'altura màxima del dispositiu, mostrant / ocultant el banner
